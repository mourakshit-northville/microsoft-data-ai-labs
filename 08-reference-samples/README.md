## How to use this index

For each topic, prefer one of these portfolio-friendly approaches:

1. Follow the upstream lab and write your own implementation notes.
2. Extend a sample with a new scenario and clearly document the delta.
3. Fork an upstream repository when preserving history is useful.
4. Copy only license-permitted material, retaining attribution and the license notice.
5. Build a fresh demo that references upstream ideas without copying implementation.

This creates a stronger technical record than bulk-copying unrelated repositories because a reviewer can see the reasoning, adaptation, and architecture decisions behind the work.
